Built-up areas
==============

.. mf-model-hero:: built-up-areas

.. note::
   This model is no longer a default model. It is available on request.

How it works
------------

This model detects built-up areas from satellite imagery without focusing on individual buildings. It segments urban blocks as a whole, providing a fast and cost-effective way to monitor urban development and analyze land use.
